# Module Positioning

## Web Client

- Transparent console
- Task management
- Status audit
- Proposal view
- Diff, check output, and review conclusion display
- Adoption entry

## Personal Assistant

- Discover optimization directions
- Write proposals
- Advance state through the program engine
- Generate reminders and summaries
- Respect automation settings

## Mobile Channels

- Lightweight notification
- Summary view
- Pause, continue, adopt, and other simple actions
- No complex diff review

## Container Agent

- Isolated execution
- Research and code inspection
- Code implementation on work branch
- Tests and checks
- Review and bug investigation
