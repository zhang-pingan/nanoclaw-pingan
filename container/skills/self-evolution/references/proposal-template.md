# Proposal Template

Use this structure inside the `proposal` string.

```markdown
# Title

## Goal
One concrete improvement and its success criteria.

## Current State
Relevant code, docs, settings, state, or behavior observed.

## Proposed Change
Small implementation plan with affected modules.

## Risk
Risk level and reason.

## Tests
Specific checks or tests that should pass.
```

Keep the proposal concise and implementation-ready. Do not include multiple unrelated directions.
