G0.2 provides the common artifact envelope, exact `VersionedRef`, strict JSON, canonical/domain-separated SHA-256, foundation fixtures, and the conformance entry point. The G2 semantic-correction Contract, per-case inputs, actual Compiler candidate, and working review bundle remain the exact, non-publishable `WORKING` source set.
