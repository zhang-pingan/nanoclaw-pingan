# Dynamic Workflow Contract Pack

This directory is the machine-readable authority for Dynamic Workflow Runtime contracts. G0.2 provides the common artifact envelope, exact `VersionedRef`, strict JSON, canonical/domain-separated SHA-256, foundation fixtures, and the conformance entry point. G0.3 adds closed Definition, Recipe, Runtime Command, Transition, Feature Manifest vNext, Card Presentation, Source IR, and Compiled IR schemas with TypeScript key/union conformance and positive/negative fixtures. G0.4 adds closed Compiler Error, Runtime Fact/Event, Permission, Command Reason/Denial catalogs; runtime state transition tables; the command authorization table; and the declarative T0-T8/T6e transaction protocol table. G0.5 adds the immutable `local_single_user_safety@1`, closed hot-reload Capacity baseline, Product Floor, Retention policy, complete per-field Enforcement Matrix, and the explicitly uncertified `local_single_user_sqlite@1` candidate. G0.6 adds the canonical metadata source for all 74 Normative Logical Schema objects, complete expanded column metadata, internal typed relations, explicit external-reference validators, CHECK/UK/FK/index intent, and the fixed query intent catalog. G0.7 adds the machine-generated `WorkflowRuntimeAbsenceBaseline`, `ProductSurfaceCoverageManifest`, and `MigrationCandidateBoundaryManifest`.

`safety/` contains G0.5 contracts. `sqlite/` contains the G0.5 SQLite candidate plus G0.6 logical metadata artifacts. `static/` contains the three G0.7 closed schemas and generated manifests. The SQLite candidate has null release/native/SQLite observation fields and is not certification evidence. G0.6 records logical type/nullability/relation/constraint/index/query intent only: it contains no SQL text, executable migration, executable Schema Manifest, Supported Limits, Store, connection factory, SQLite open, or PRAGMA execution. G0.7 performs absence-only SQLite schema inspection and does not execute Runtime SQL or migrations. The Golden draft/sealed roots remain reserved. G0.3 fixtures live under `conformance/closed-schemas/`, G0.4 fixtures under `conformance/catalog-protocols/`, G0.5 fixtures under `conformance/safety-sqlite/`, G0.6 fixtures under `conformance/logical-schema/`, and G0.7 fixtures under `conformance/static-absence/`; none is Golden Draft or Sealed Golden data. The protocol, profile, logical-schema, and static-gate artifacts do not implement Store, Registry, Compiler, or Runtime semantics.

Use the managed toolchain for both commands:

```bash
./scripts/runtime-toolchain.sh exec -- npm run contracts:generate
./scripts/runtime-toolchain.sh exec -- npm run contracts:check
```

`contracts:generate` refreshes G0.2-G0.6 plus the deterministic G0.7 static gates. G0.7 derives its evidence from the TypeScript AST/import graph, Web route enumeration, Electron DOM inventory, Feature manifest parser, SQLite schema inspection, and configured filesystem roots. Migration candidate bytes are read only by the checksum verifier and never enter source-hit analysis. CI runs `contracts:check` without writes and fails on removed source/API/UI/schema/filesystem/resource reachability, protected capability loss, test root leakage, migration-candidate reachability, surface status drift, or prior-pack identity drift. The G0.2-G0.6 manifests remain byte-identical and are pinned by the G0.7 manifest.
